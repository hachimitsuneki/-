# Music Separation Workbench

Score-informed music source separation research project using NVIDIA Audio-SDS as the primary separation direction.

The current repository baseline contains the Slice 0–3 scaffold:
- project/run/artifact provenance
- MusicXML canonical score model
- score↔audio alignment layer
- score/alignment→NVIDIA separation planning

Start with `PROJECT_HANDOFF.md`, then read the Slice 3 and Audio-SDS documents under `docs/`.
